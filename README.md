# New Hope Church Website

A static website for New Hope Church, built with HTML, CSS, and JavaScript.

## Wireframes
The live design can be viewed here, "https://www.figma.com/design/ekGGhbOf0Lnov2Kty1Hste/church-wireframe?node-id=1-470&t=5NoGYjqTf7kOv42L-1", which outlines the overall layout and userflow.

## Features
- Home, About, and Connect pages
- Events listing
- Online giving page
- Small groups info
- Testimonies
- Youth camp registration form
- Youth camp photos ("Rooted in Christ"): campers scan a QR code to take and send photos (no login); leaders move the best ones from the Drive inbox to the camp album; campers browse them on the page (all photos, by team, by challenge) and like them, and they play on the projector (`camp-photos`, `camp-photos-live`, `camp-photos-poster`; setup steps are at the top of `apps-script/camp-photos.gs`)

## Tech Stack
- HTML5
- CSS3
- JavaScript
